# 🎹 Keyboard Piano

A fully functional piano game playable directly in your browser using your keyboard!

## Features

- **Play with your keyboard**: Press keys Q-P, A-L, and Z-M to play different notes
- **Professional sound**: Clear, loud notes using Web Audio API
- **Piano-style keys**: Looks and feels like a real piano keyboard
- **Fully responsive**: Works perfectly on phones, tablets, and desktops
- **Landscape support**: Auto-rotates for tablets and phones in landscape mode
- **Multiple octaves**: Spans three octaves for a complete musical range

## How to Play

1. Open the website in your browser
2. Press keyboard keys to play notes:
   - **Row 1 (Q-P)**: High notes (C4 to E5)
   - **Row 2 (A-L)**: Mid notes (C3 to D4)
   - **Row 3 (Z-M)**: Low notes (C2 to B2)
3. Hold keys for sustained notes
4. Play multiple notes simultaneously by pressing different keys

## Browser Compatibility

Works in all modern browsers that support Web Audio API:
- Chrome/Edge
- Firefox
- Safari
- Opera

## Technical Details

Built with:
- HTML5
- CSS3 (with responsive design & media queries)
- Web Audio API (for sound generation)
- Vanilla JavaScript
